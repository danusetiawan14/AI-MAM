Version: 1.0

\# 1. Design Principles



\## AI First



AI insights harus selalu terlihat.



\## Search First



Search menjadi fitur utama.



\## Media First



Video preview selalu menjadi fokus utama.



\## Enterprise Ready



Mendukung ribuan hingga jutaan asset.
